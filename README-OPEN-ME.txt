UAP PATTERN DOSSIERS — offline phone pack
=========================================

WHAT THIS IS
  A fully self-contained documentary app. 5 dossiers, narrated audio, maps,
  and a live AI investigator. No internet needed once this folder is on your phone.

HOW TO OPEN (the ONLY step that matters)
  Open the file:  uap-command-center.html
  Open it from your phone's FILES app (Apple Files / Google Files) — NOT from
  inside the Dropbox app's preview. Dropbox's preview shows HTML as text and
  will not run the app.

TO USE IT
  Tap the "Pattern Dossiers" button at the top -> pick a dossier ->
  press "Play episode" to auto-advance the narrated chapters.
  In an "investigator" chapter, tap a case to run the 5-step analysis live.

OFFLINE (for Ireland with no signal)
  If using Dropbox: in the Dropbox app, long-press this folder ->
  "Make available offline" BEFORE you lose signal. Then open the HTML via Files.
  (iCloud Drive / on-device Files works the same way with no extra step.)

DO NOT
  - Do not move files out of this folder or rename subfolders.
  - Keep audio/ and vendor/ sitting right next to the .html file.
  - Do not open via a "127.0.0.1" or "localhost" address — that only works on the laptop.

The 5 dossiers:
  Nuclear Sentinel (9 ch, ~13 min)
  The Boyne Valley (8 ch, ~11 min)   <- the one for the Ireland trip
  The Silent Triangle (6 ch, ~7 min)
  The Radar-Visual Encounter (6 ch, ~7 min)
  The Recurring Hotspot (5 ch, ~6 min)
